## 🔨 Current project
 
### [secure-fastapi-lab](https://github.com/mazarzycki/secure-fastapi-lab)
 
A FastAPI + PostgreSQL service, containerized and hardened, with a security pipeline built into CI (pytest, Hadolint, Gitleaks, Semgrep, Trivy).
 
I deliberately introduce realistic vulnerabilities (SQL injection, broken JWT validation, IDOR, mass assignment), then exploit, detect, fix and regression-test each one. The write-ups document what automated scanners catch and, more importantly, what they miss.
 
*In progress: v1.0 due November 2026.*
